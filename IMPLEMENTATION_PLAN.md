# Implementation plan

1. Foundation: npm workspaces, shared validation/constants/types, design tokens, Express, authentication and tenant repositories.
2. Platform: hotels, owners, plans, subscriptions, invoices, collections and reports.
3. Hotel: customers, meal plans, subscriptions, attendance and leave.
4. Finance: invoice/payment allocation, advances, daily sales, vendors, purchases, payments, expenses.
5. Reporting/settings: common filters, CSV/Excel/PDF, profiles, themes and credentials.
6. Validation: financial unit tests, MongoDB integration, browser workflows, production builds and deployment docs.

Acceptance is defined by the supplied master prompt. PROGRESS.md records actual verification and gaps; a compiled project alone does not satisfy acceptance.
